# CLI Game

A command-line implementation of Wheel of Fortune.

## Features

- Three-player gameplay
- Randomized spinning wheel
- Money cards with different values
- BANKRUPT cards
- LOSE A TURN cards
- Randomly selected puzzles
- Letter guessing
- Puzzle solving
- Round-based scoring
- Round winners
- Overall game winner

## Getting Started

**1. Clone the repository:**
```bash
git clone https://github.com/<your-username>/wheel-of-fortune-cli.git
```
**2. Navigate into the project folder:**
```bash
cd wheel-of-fortune-cli
```
**3. Install dependencies:**
```bash
npm install
```
**4. Running the game:**  
```bash
npm start
```
**Or**  
```bash
node src/index.js
```
